# 📱 DocScan
![VibeScanner Logo](icon-192.png)


Полностью автономный офлайн-сканер документов прямо в вашем браузере. Приложение построено по технологии **Progressive Web App (PWA)**, что позволяет установить его как нативное приложение на iOS и Android без публикации в магазинах приложений.

Приложение работает **100% локально на вашем устройстве** и не отправляет ваши конфиденциальные документы на сторонние сервера.

---

## ✨ Ключевые возможности

*   📷 **Быстрый захват:** Интеграция с системной камерой смартфона или загрузка готовых файлов из галереи.
*   📐 **Автоматический контур:** Интеллектуальное определение краев листа бумаги на фото с помощью компьютерного зрения.
*   🔄 **Выравнивание перспективы:** Автоматическая трансформация заваленных углов кадра в идеальный ровный вертикальный документ.
*   🪄 **Фильтр «Магический цвет»:** Адаптивное бинаризованное повышение контрастности (Adaptive Thresholding) — серый фон становится белым, а текст четким и насыщенным для удобного чтения.
*   📄 **Многостраничный экспорт:** Компоновка нескольких отсканированных страниц в один единый документ.
*   💾 **Сохранение в PDF:** Быстрая генерация и скачивание готового файла `.pdf` на внутреннюю память телефона.
*   ✈️ **Офлайн-режим (PWA):** Приложение кэшируется при первом запуске и может полноценно работать без доступа к интернету (например, в самолете или при плохой связи).

---



## 🔒 Конфиденциальность
Ваша безопасность — главный приоритет. Все вычисления, обрезка картинок и сборка PDF-файла происходят **внутри процессора вашего телефона**. Приложение не имеет серверной части (backend) и физически не способно передать ваши документы в сеть.
